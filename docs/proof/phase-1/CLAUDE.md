## Working style

- The student has no coding background. Guide step by step: explain what to change and why, propose small edits one at a time, and wait for confirmation before moving on.
- Do not run `git commit` / `git push`. The student commits manually. Never add `Co-Authored-By` lines.
- Ask before running anything that calls paid LLM APIs (`--part 4`, `main.py` with no args, `scripts/grade.py`).
